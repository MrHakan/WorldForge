# WorldForge v4.0 — World Building & Pixel Civilization Layer

WorldForge v4.0 adds a visual civilization layer on top of the existing simulation instead of creating a separate decorative world. Each settlement receives a deterministic worldbuilding profile derived from live simulation state and can be inspected as a compact pixel-art scene.

## Settlement worldbuilding profiles

Every settlement receives a bounded profile containing settlement type, culture style, biome style, wealth/defense/importance tiers, population, physical condition, municipal service quality, housing/slum pressure, geographic flags, district plan, aggregate structure inventory, visual identity text and a deterministic preview seed.

The model consumes existing systems rather than inventing parallel values. Inputs include City prosperity, trade and guard strength; Housing shortage/overcrowding/slum pressure; Municipal services; Workforce population; Culture identity; physical biome geography; and v3.0 realm prestige/power.

## District generation

Existing v0.4 city districts are preserved and normalized into visual district archetypes where available. The v4.0 layer supports:

- old town;
- residential quarter;
- market district;
- harbor district;
- temple district;
- military district;
- noble quarter;
- civic center;
- industrial/crafts district;
- slums;
- outskirts/farmland.

Settlements without a full city district graph receive a deterministic compact plan based on population, geography and defense. Coastal/river settlements can materialize a harbor; heavily defended settlements expose military/fortification structures; stressed housing markets expose slum pressure.

## Structure archetypes

`structure-archetypes.js` defines reusable data-driven structures rather than persisting thousands of individual buildings. Initial coverage includes houses by wealth tier, barracks, watchtowers, walls, gates, market stalls, warehouses, docks, shipyards, temples, workshops, farm clusters, granaries, civic halls, wells and road segments.

Each archetype carries category, district affinity, footprint, height and modular prop hints for later visual expansion.

## Pixel civilization renderer

`pixel-structure-renderer.js` produces deterministic SVG previews with `shape-rendering="crispEdges"`. The renderer uses modular pixel primitives instead of external sprite dependencies and varies palette/layout by biome, culture, coastal/river geography, fortification level, district placement and structure composition.

The preview is derived output and is not serialized, keeping save files compact. Re-rendering the same settlement profile produces the same scene and fingerprint.

## Worldbuilding Atelier

The new workspace provides:

- world-level settlement/district/structure KPIs;
- settlement selection;
- deterministic pixel preview;
- visual identity and simulation traits;
- district population/wealth/condition breakdown;
- structure inventory;
- JSON Worldbuilding Ledger export.

UI updates use revision keys, `requestAnimationFrame`, hidden-tab suspension and a slow polling fallback.

## Universal Encyclopedia

v4.0 adds:

- `settlement_worldbuilding`;
- `district_profile`;
- `structure_archetype`;
- `settlement_visual_identity`.

These articles cross-link settlements, districts and structure archetypes and are included in Wiki search/export surfaces.

## Performance model

WorldForge does not persist one entity per house, wall block or market stall. The save state stores one compact profile per settlement with district-level aggregate structure counts. Runtime lookup tables live in `WeakMap` caches and are never serialized.

This keeps the visual layer suitable for long-running deterministic simulations while leaving room for later zoom/detail releases.

## Validation

The dedicated v4.0 gate validates:

- v3.0 World Order compatibility;
- JavaScript syntax for the full v4.0 runtime surface;
- structure-archetype registry validity;
- complete settlement profile coverage;
- district and structure generation sanity;
- deterministic crisp-edge pixel SVG generation;
- Universal Encyclopedia integration;
- runtime cache reuse;
- same-year idempotency;
- deterministic `4 years == 2 + 2` caller chunking;
- Workforce and World Order determinism under the new bridge;
- save/export round trips;
- maritime harbor logic and fortification structure exposure where applicable.

## Causal chain

```text
Population + prosperity + housing + municipal services + geography + culture + realm importance
  -> settlement identity
  -> district mix / wealth / condition
  -> aggregate structure inventory
  -> deterministic pixel civilization scene
  -> Worldbuilding Atelier / Encyclopedia / export
```

## Next visual expansion

The natural follow-up is a deeper historical-landscape layer: ruins, landmarks, wonders, old battlefields, bridges, canals, strategic chokepoints, culture-specific sprite families and higher-detail settlement zoom levels. The v4.0 data model intentionally leaves these as derived, bounded additions instead of requiring a rewrite.
