# v5.3.0 - Living Atlas HD

Close zoom now renders visible terrain tiles at a resolution selected from camera scale and device pixel density, instead of enlarging a single low-resolution world image. Tile memory is bounded; distant views retain a cached overview. Zoom extends to 20x and settlement selection includes an Explore settlement action.

Settlements are drawn from projected XYZ building faces at display resolution. Twenty-seven structure types provide tents, pavilions, campfires, adobe and courtyard homes, granaries, wells, farms, shrines, townhouses, markets, smithies, warehouses, halls, temples, keeps, gatehouses, watchtowers, barracks, manors, academies, observatories, aqueducts, clocktowers, mills and gardens.

Five visual stages follow the simulation: encampment, clay village, brick town, fortified city and civic metropolis. Agriculture enables permanent villages; masonry and bronze adoption unlock brick towns; ironworking and siege engineering allow fortifications; sanitation and mechanical engineering support mature cities. Population gates prevent tiny villages from turning into metropolises. Seeded layouts remain stable, population controls density, and shoreline placement excludes residential structures from water. Zoom reveals streets and individual structures.

Historical views exclude discoveries that have not happened yet. Because the existing simulation does not record yearly adoption, historical architectural maturity uses discovery dates with an estimated diffusion delay; the selection card labels this estimate. Current views use actual adoption. The model and save schema are unchanged.

Validation includes deterministic stage and population gating, historical discovery filtering, the rendering regression suite, existing Pages and atlas browser checks, and a new device-pixel-ratio-2 browser test with five isolated visual fixtures. Test fixtures are never saved or exported into user worlds.
