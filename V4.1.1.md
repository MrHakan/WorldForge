# WorldForge v4.1.1 — Pixel Civilization Diversity Polish

v4.1.1 is a focused visual-quality follow-up to the v4.1 Historical Landscape & Architecture release. It keeps simulation and save-state behavior unchanged while making the Pixel Civilization layer better reflect the architecture variants already produced by the worldbuilding model.

## Why this patch exists

v4.1 introduced a broad culture-variant registry, but several registered forms still fell back to their generic base glyph because the renderer had no dedicated drawing branch for them. This was most visible for:

- `gable_house` (Northern Timber merchant house)
- `stucco_house` (Maritime Stucco house)
- `trading_post` (Frontier Stockade merchant house)
- `stockade_barracks` (Frontier Stockade barracks)
- `caravan_house` (Steppe Court merchant house)

The structures were semantically correct but visually less distinct than intended.

## Pixel polish layer

`pixel-art-polish.js` now decorates deterministic structure SVG groups after the v4.1 base renderer runs. The layer is intentionally additive so it does not duplicate or destabilize simulation logic.

The polish layer adds culture-specific pixel details such as stepped gables, stucco facade accents, trade signs and porches, timber stockade bracing, caravan-house arches, balconies, arcades, guild signs, hall crests, river stilts, coastal beacons and warehouse/quay details.

The enhanced set covers both previously generic fallbacks and architecture forms that shared a common base silhouette in v4.1. The base `data-variant` metadata remains intact and polished groups expose `data-pixel-polish="4.1.1"` plus a `data-polish-detail` marker.

## Compatibility

- No persistent simulation state is added.
- No save schema changes are required.
- v4.0 pixel-format and v4.1 renderer markers remain intact.
- The Worldbuilding loader applies the polish after the v4.1 renderer and before the Worldbuilding engine/UI bootstraps.
- Rendering remains deterministic for the same settlement profile and seed.

## Regression coverage

`tests/pixel-art-polish.mjs` verifies the five important former generic-fallback variants, renderer version markers, deterministic settlement SVG output, deterministic fingerprints and distinct Northern/Coastal culture output.

The v4.1 GitHub Actions gate now syntax-checks and runs the polish regression in addition to the existing v4.0/v4.1 compatibility chain.
